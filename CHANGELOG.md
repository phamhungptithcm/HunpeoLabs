# Changelog

All notable source releases of the Hunpeo Labs website are documented here.

## [0.1.0] - 2026-07-28

### Added

- Multi-page Hunpeo Labs marketing website and responsive design system.
- Services, Products, Work, Resources, About, Careers, Contact, and Privacy
  routes with typed detail content.
- Source-verified SEO metadata, structured data, sitemap, robots, RSS, and
  machine-discovery foundations.
- Fail-closed contact delivery foundation and production configuration checks.
- CI, cross-browser E2E, Lighthouse, security headers, health endpoint,
  preview guidance, and rollback documentation.
- Deterministic release build and tag-based GitHub Release workflow.

### Release boundary

- No production deployment is included.
- Contact delivery remains disabled until verified external configuration is
  supplied.
- Blog, Research, and Talks remain non-indexable until reviewed content exists.
