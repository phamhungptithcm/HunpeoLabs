# Hunpeo Labs Website v0.2.0

This release makes the website easier to understand and more enjoyable to
explore. Product stories are clearer, the company principles feel more human,
and the production path is now fully defined for Firebase App Hosting.

## What is new

- Richer product pages for AI Agent Kit, IncOv, and Gig, with focused system
  visuals, short product videos, and source-backed descriptions.
- A rebuilt Principles experience around one practical loop: See, Map, Build,
  Prove, Scale.
- Shorter, more natural Principles copy with clear Do and Avoid guidance.
- A calm one-time motion sequence that carries one blue signal through the
  Principles loop, then reveals each detail as it enters the viewport.
- A clearer Privacy page with a code-native signal visual and plain-language
  explanations.
- New site icon and web app manifest.

## Experience and accessibility

- Dedicated desktop and mobile compositions for the Principles flow.
- Reduced-motion users receive the complete final state immediately.
- Content remains readable if JavaScript or animation is unavailable.
- Responsive checks cover mobile layouts, 200% text scaling, and horizontal
  overflow.

## Delivery and operations

- Firebase App Hosting configuration for backend `hunpeolabs` in project
  `hunpeolabs-prod`.
- A production preflight that checks the exact project, backend, public origin,
  and contact-delivery policy before deployment.
- CI browser tests now run against the production Next.js server.
- Local screenshots, reports, caches, and environment files stay outside the
  release and deployment source.
- Contact delivery remains disabled until a reviewed provider and its secrets
  are configured.

## Verification

The release gate covers:

- ESLint, TypeScript, unit tests, and a production Next.js build.
- Chromium desktop and mobile end-to-end coverage.
- Firefox and WebKit smoke coverage.
- Lighthouse quality and SEO thresholds.
- Firebase production configuration preflight.

## Compatibility

- Node.js 24 or newer
- pnpm 11.9.0
- Next.js 16.2.12

There are no database migrations, persisted application-state changes, new
runtime dependencies, or secret changes in this release. Rollback uses the
previous Firebase App Hosting rollout and the `v0.1.0` source release.
