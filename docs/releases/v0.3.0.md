# Hunpeo Labs Website v0.3.0

Release candidate; not yet published or approved as production-ready.

## Changes

- Integrated Journal and Studio CMS with Google-only verified identity,
  server-side editorial grants, draft/revision workflows, private media,
  moderated reader comments and article sharing.
- Shared account/navigation, writing controls and responsive page updates.
- Consent-only Firebase Analytics, security-patched Next.js 16.3.8 and bounded
  transitive dependency overrides.
- Finite service catalog returns real 404 status for unknown slugs.
- Explicit Codex/Claude adapter selection and matching generated-skill checks.

## Release gates

Current candidate validation, source identity and live provider acceptance are
recorded in HUNPEOLABS-RELEASE-004 completion/review records. Passing local or
emulator tests does not establish live Google login, IAM, ingress, media privacy,
backup restoration or production readiness. Do not publish until all required
gates pass and this candidate marker is replaced with verified release evidence.

## Configuration and rollback

Reuse hunpeolabs-prod / hunpeolabs and existing private database/bucket. CMS
requires matching Firebase server/client configuration, a Secret Manager-backed
rate-limit secret, verified trusted ingress and minimal runtime media-write
permissions. Contact delivery remains disabled. One Tap remains optional.

No destructive schema migration. Preserve Firestore access policy, client
deny-all rules, media and Auth identities. Disable the CMS feature flag to pause
new application traffic; fix forward using patched source. Never reset the
one-time editorial policy marker or silently restore revoked access.
