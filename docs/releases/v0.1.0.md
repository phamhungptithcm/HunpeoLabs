# Hunpeo Labs Website v0.1.0

The first source release of the Hunpeo Labs marketing website establishes a
professional, multi-page foundation for presenting services, products,
open-source work, and the company's engineering approach.

## Highlights

- Purpose-built pages for Services, Products, Work, Resources, About, Careers,
  Contact, Privacy, and detailed service/product profiles.
- Unified typography, grid, palette, header, footer, responsive behavior, and
  restrained motion system.
- Product coverage for AI Agent Kit and IncOv, plus verified public repository
  links for AI Agent Kit and Gig.
- Source-backed service positioning across web, mobile, AI-agent, AI-product,
  platform-modernization, and architecture/governance work.

## Search and machine discovery

- Canonical metadata, Open Graph, Twitter metadata, sitemap, and fail-closed
  production indexing.
- Source-verified Organization, WebSite, Service, Product,
  SoftwareSourceCode, and Breadcrumb JSON-LD.
- A typed `/llms.txt` discovery aid that does not override crawler directives.
- Lighthouse SEO enforced as a hard release gate at 90 or higher.

## Contact, privacy, and security foundations

- Server-side contact validation, honeypot protection, process-local rate
  limiting, delivery timeout, and honest unavailable/error/success states.
- Contact delivery remains disabled until a verified provider and reviewed
  retention statement are configured.
- Baseline CSP, HSTS in production, clickjacking protection, MIME-sniffing
  protection, referrer controls, and browser-permission restrictions.
- Privacy content reflects only integrations that are actually configured.

## Quality and browser coverage

- TypeScript, ESLint, and Vitest quality gates.
- A 32-scenario Chromium desktop/mobile E2E suite.
- Firefox and WebKit critical-route smoke coverage in CI.
- Production build and Lighthouse checks for Home, Services, and Contact.
- Health endpoint, rollback guidance, preview-readiness guidance, and
  production-environment validation.

## Launch requirements

This release does not deploy the website. Before production launch, the owner
must still:

1. configure the verified HTTPS production origin with
   `NEXT_PUBLIC_SITE_URL`;
2. select and configure a real contact provider if form delivery is required;
3. review Privacy against the selected hosting, contact, monitoring, and
   retention configuration;
4. complete preview review and production deployment under separate approval.

## Compatibility

- Node.js 24 or newer
- pnpm 11.9.0
- Next.js 16.2.12

There are no database migrations or persisted application-state changes in
this release.
