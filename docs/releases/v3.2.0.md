# Hunpeo Labs Website v3.2.0 — Writing, Reading and Performance

## Changes

- Improve Studio writing with slash commands, block actions, focus mode, image paste/drop, tables, metadata previews and recoverable trash.
- Improve article reading with section navigation, copy controls, image zoom and Mermaid diagram/source switching.
- Add bounded public search, topic-aware related articles and deterministic automatic comment spam checks with moderator reasons and server-only reputation.
- Share session checks across account controls, add server loading shells and stream primary articles independently of related queries. Preserve readable no-JavaScript fallback.
- Recover account-scoped drafts and authorize scheduled publishing with verified scheduler identity.
- Add Satsunic extension privacy disclosure and describe comment checks and retention.

## Compatibility and rollout

No destructive data migration, Firestore rules change or billing activation. New optional comment reputation fields are server-only; old pending comments remain pending. Existing main security overrides, current disabled Analytics/Google One Tap activation flags and atomic identity/global rate limiting are retained.

## Validation

Exact integrated candidate evidence is recorded in `.ai/proposals/HUNPEOLABS-RELEASE-043-completion.md`. Local/browser/emulator evidence does not certify live OAuth, actual scheduled publication or spam-detection accuracy. Performance timings were measured on a prior scoped synthetic candidate and are not production field metrics.

## Rollback

Redeploy the previous immutable App Hosting rollout/revision. Already automatically approved comments remain published unless moderated individually. No schema rollback required; private reputation records can remain compatible with the prior code.
